# Tour Company Landing Page

A guided practice project from John Smilga's HTML & CSS course on Udemy.

**Tech:** HTML, CSS
**Project Type:** Guided Exercise / Course Project

---

## Overview

This project is a responsive tour company landing page built with semantic HTML and pure CSS.

The implementation was completed independently while following the concepts and requirements introduced in the course. The main focus was practicing practical CSS skills, responsive layouts, reusable styles, and modern CSS techniques.

---

## Implementation Process

1. Built the initial HTML structure independently.
2. Implemented the CSS styling and layout based on the requirements introduced in the course.
3. Applied responsive techniques for different screen sizes.
4. Refactored styles to improve reusability and maintainability.

---

## What I Learned / Practiced

* CSS custom properties (`--variables`) for reusable values
* Utility classes for reducing repetitive CSS
* **Flexbox** and **CSS Grid** for layout
* Responsive design across desktop, tablet, and mobile breakpoints
* Semantic HTML structure
* Organizing CSS for maintainability and reusability
* Modern CSS techniques and best practices

---

## Purpose

The purpose of this project was to strengthen practical CSS skills by building a complete, responsive website rather than focusing only on isolated CSS exercises.
